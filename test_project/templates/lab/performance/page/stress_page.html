Deck: spawning, dropping and keeping children

Touch re-renders the deck and keeps its cards. Grow and Shrink spawn and drop a card. +1 on a card raises its counted event: the deck hears it through a Glue.listener, which only hears descendants, and re-renders keeping its cards; every tally below hears it too.

Each tally lists counted in rerender_on, which hears the event from anywhere on the page, and shows when it last rendered. All the components one response wakes, the deck included, re-render in a single follow-up request, so a card's +1 should be two calls however many tallies there are.
